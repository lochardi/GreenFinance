# Green Finance: Drought, Agriculture, and Financial Valuation

Agricultural activities are highly exposed to drought risk through water availability constraints, yield variability, and input cost pressures. 

For institutional investors holding equity stakes in agricultural firms, these factors translate into cash flow volatility and increased valuation risk. 

The objective of this project is to build a transparent modelling framework linking drought-related hazards to agronomic impacts and, ultimately, to financial valuation metrics.
